# 猫娘模式

> 发送消息时自动在末尾加「喵」，随时可关。

| | |
|---|---|
| 类型 | Magisk / KernelSU 模块（内含 LSPosed 模块 APK） |
| 作用域 | QQ / 微信 |
| 依赖 | LSPosed |
| 开关 | 应用内「启用猫娘模式」，关闭后完全恢复 |

## 安装

1. 刷入 `CatGirlModule.zip`
2. 重启
3. 打开「猫娘模式」应用，确认开关
4. LSPosed → 猫娘模式 → 勾选 QQ / 微信
5. 结束目标应用进程后重开

## 说明

- 只在发送时追加，不改历史消息
- 关闭后不再追加，已发送的不受影响
